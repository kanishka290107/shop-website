## 📁 Website Pages & Features
- **Home (`index.html`)**: Hero section, animated marquee brand ticker, featured collections, luxury pillars, quick contacts, and Google Maps integration.
- **About Us (`about.html`)**: Story of Bacchomal Collection, heritage, 100% authenticity guarantee, and in-store boutique experience.
- **Our Brands (`brands.html`)**: Brand directory with real-time live search filter and direct WhatsApp stock inquiry buttons.
- **Curated Collections (`collections.html`)**: Category filter tabs (*Polos & Tees, Luxury Shirts & Suits, Designer Denim, Jackets & Outerwear, Accessories*) and quick inquiry modals.
- **Visit & Contact (`contact.html`)**: Interactive contact & styling consultation form with optional WhatsApp forwarding, directions, store hours, and embedded Google Map.

## 🚀 How to Run Locally
Open `index.html` directly in any web browser, or launch a simple local HTTP server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
